Comet (Perplexity's browser) blocks extensions from running on the Perplexity website / the Comet new tab page (they possibly do this so no adblock extensions can block Perplexity's ads/trackers?).

This means extensions like [Complexity](https://github.com/pnd280/complexity) couldn't work.

**v2 (Nov 2025):** this repo now ships a tiny macOS script that installs a *managed Chromium policy* for Comet which re-allows `*://*.perplexity.ai` for all extensions. No wrapper app, no special shortcut: just open Comet normally afterwards. It survives Comet updates and does not modify `Comet.app` itself. It needs your password once (`sudo`) because the policy lives in `/Library/Managed Preferences`.

> **Why v2?** The original (v1) trick flipped `Allow-external-extensions-scripting-on-NTP` in `Local State` right before launch via a `Comet - CPLX` wrapper app. Current Comet builds (verified on 156.0.8078.x) no longer write or honour that key, so the wrapper silently did nothing (issues #2, #4). The policy approach was found by Complexity's developer Pham Ngoc Duong for Windows ([details](https://github.com/pnd280/complexity/blob/nxt/perplexity/extension/docs/comet-enable-extensions.md)); this is the macOS port, with status/uninstall and automatic cleanup of the old v1 wrapper.

More background:
https://github.com/pnd280/complexity/blob/nxt/perplexity/extension/docs/articles/comet-enable-extensions-article.md

This is pretty huge as it lets us not only remove ads/tracking from Comet's perplexity homepage and sidebar chat, but also lets us do some really cool stuff. For instance:
- The Comet sidebar chat uses a *tiny*, crappy LLM. You can't change this! The summaries generated by it are trash. Complexity is working to bring the model picker to the sidebar chat :)

## One-click install

```
curl -fsSL "https://raw.githubusercontent.com/theJayTea/Comet-Patcher-to-Unblock-Perplexity-Extensions/main/comet-patch-macos.sh" | bash
```

Enter your Mac password when asked, then fully quit Comet (Cmd+Q) and reopen it. Extensions will now work on Perplexity when using Comet :) Great for adblock and stuff like Complexity.

## What it does

- Writes `/Library/Managed Preferences/ai.perplexity.comet.plist` containing:
  ```
  ExtensionSettings -> "*" -> runtime_allowed_hosts: ["*://*.perplexity.ai"], runtime_blocked_hosts: []
  ```
  Managed policies override Comet's built-in block list, so every extension regains access to perplexity.ai.
- Restarts `cfprefsd` so the policy is picked up immediately.
- Removes the old v1 `~/Applications/Comet - CPLX.app`, its log and `Local State` backup if they are still around.

Verify: open `comet://policy` in Comet; `ExtensionSettings` should be listed with the perplexity.ai host.

## Manual install / other commands

```
bash comet-patch-macos.sh             # install
bash comet-patch-macos.sh --status    # check whether the policy is active
bash comet-patch-macos.sh --uninstall # remove the policy (and v1 leftovers)
```

## Uninstall

```
bash comet-patch-macos.sh --uninstall
```
or by hand: `sudo rm "/Library/Managed Preferences/ai.perplexity.comet.plist"` and restart Comet.

## Troubleshooting

- **Extensions still blocked after install:** make sure Comet was fully quit (Cmd+Q, not just the window closed) and reopened. Check `comet://policy`; if `ExtensionSettings` is missing, run `bash comet-patch-macos.sh --status`.
- **Comet installed somewhere unusual** (e.g. `/Applications/AI Tools/Comet.app`): doesn't matter anymore, the policy is keyed on the bundle id `ai.perplexity.comet`, not the app path (fixes #3).
- **Still using the old `Comet - CPLX` shortcut?** Delete it (the installer does this for you) and launch Comet from its normal icon.
- **Windows:** use Complexity's own installer: `irm "https://cdn.cplx.app/comet/win.ps1" | iex` in an elevated PowerShell.
